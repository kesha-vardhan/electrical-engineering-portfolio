# Industrial LT Cable Sizing & Running Voltage Drop Analysis

## Project Overview

This project covers the cable-sizing analysis of a 415 V, 3-phase industrial power-distribution system.

The study progresses from the electrical Single Line Diagram (SLD) through feeder load assessment, cable selection, current-carrying-capacity verification and running voltage-drop analysis.

## System Parameters

| Parameter | Value |
|---|---|
| System Voltage | 415 V |
| System | 3-Phase AC |
| Frequency | 50 Hz |
| Power Factor | 0.8 |
| Conductor | Aluminium |
| Insulation | XLPE |
| Voltage Drop Criterion | 3% |

## Running Voltage Drop

The running voltage drop is calculated using:

**VD = √3 × I × L × (R cosφ + X sinφ) / N**

For the project:

**Power Factor = 0.8**

**cosφ = 0.8**

**sinφ = 0.6**

The voltage-drop percentage is calculated as:

**VD% = (VD / 415) × 100**

The project workbook uses a **3% running-voltage-drop criterion**.
